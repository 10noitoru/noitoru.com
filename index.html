Fig.02 — Service

Before / Afterこんな録音に。

雑音の種類によって、効く処理は変わります。音源の状態を聞いてから、いちばん聞き取りやすくなる方法を選びます。青い線が通ったところから、処理後の波形に変わります。カーソルで左右になぞると、好きな位置で処理の前と後を比べられます。

CASE 01HUM

エアコン・換気扇の音

ずっと鳴っている「ブーン」「サー」という音を下げて、声を前に出します。

CASE 02RUMBLE

車内・電車・屋外

走行音や街の音に埋もれた会話を、聞き分けられるところまで整えます。

CASE 03MUFFLED

カバン・ポケットの中

布ごしにこもった声や、こすれる音を抑えて、輪郭をはっきりさせます。

CASE 04DISTANT

遠くて小さな声

離れた場所の話し声を持ち上げ、大きすぎる音とのバランスをそろえます。

CASE 05WIND

風・ふく音

マイクに当たる風の「ボッ」という音を減らします。

CASE 06PHONE

電話・スピーカーの声

通話の録音や、スピーカーから出た声の割れ・こもりを聞きやすくします。

CASE 07ECHO

会議室・ホールの響き

広い部屋で録ったインタビューや会議の、わんわんと響く音を抑えて、言葉の輪郭を出します。

CASE 08CROWD

カフェ・店のざわめき

取材先のカフェや店で、まわりの話し声や食器の音に埋もれた声を前に出します。

CASE 09TAPE

古いテープの録音

データにしたカセットや MD の「サー」という音や揺れを抑えて、家族の声などを聞きやすくします。

  • 声紋で、誰の声かを決める鑑定は専門機関へ

  • 言葉を足す・削る・つなぐ中身は変えません
  • 人を調べる・録音機を仕掛ける調査はしません

Fig.07 — FAQ

Questionsよくある質問

01ご依頼について

処理した音声は、裁判で使えますか？
当方は聞き取りやすくする処理を行うもので、鑑定ではありません。証拠としてどう使うかは、弁護士にご相談ください。ご希望の方には、原本のハッシュ値と処理内容を記した「音声処理証明書」をお付けできます（+5,000円）。
全部聞き取れるようになりますか？
お約束はできません。録れていない音を作り出すことはできず、仕上がりは元の音声の状態しだいです。そのため、正式なご依頼の前に、20秒の無料お試しで仕上がりをご確認いただいています。
内容を足したり削ったりしますか？
しません。切り貼りや削除は行わず、原本は加工しないまま保存します。
匿名で依頼できますか？
できます。お名前はニックネームでもかまいません。連絡用のメールアドレスだけはお知らせください。
探偵事務所や法律事務所から、継続して依頼できますか？
できます。継続してご依頼いただく業者さまは、請求書払い（月末締め）にも対応します。

02料金とお支払い

仕上がりに満足できなかった場合、返金はありますか？
正式なご依頼の前に、無料お試しで仕上がりを確かめていただいているため、返金はお受けしていません。
途中でキャンセルできますか？
作業を始める前なら、全額をお返しします。作業を始めたあとのキャンセルは、返金できません。

03送り方と納品

どんなファイルに対応していますか？
MP3・WAV・M4A など、一般的な音声ファイルと動画ファイルに対応します。
音声はどうやって送ればいいですか？
ギガファイル便などのファイル転送サービスで送ってください。郵送（USBメモリ・SDカード）でも受け付けます。原本は必ずお手元に残してください。
カセットテープや MD のままでも頼めますか？
データ（音声ファイル）にしてからお送りください。テープや MD をデータにする作業はお受けしていません。データにしたあとの雑音やこもりの処理は、ほかの録音と同じ料金でお受けします。

04お受けできないもの

  • 鑑定（声紋・改ざんの判定）
  • 調査そのもの
  • 違法に録音された音声
  • 重大な犯罪に関わる音声
  • 集団ストーカー・電磁波攻撃などの証明
  • 音楽・放送の加工
  • ご自身が参加している会話の録音は、お受けします

違法に録音されたものを偽って申し込まれたと分かった場合は、処理を中止し、返金しません。
